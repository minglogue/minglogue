# Minglogue

디자인, 마케팅을 거친 밍띠의 코딩 공부, 일상, 포트폴리오
그리고
반려햄스터 푸딩이의 기록을 담는 개인 블로그입니다.

## 기술 구성

- Next.js / React / TypeScript
- vinext / Cloudflare Workers
- GitHub 기반 소스 및 콘텐츠 관리

## 시작하기

Node.js 22.13 이상이 필요합니다.

```bash
pnpm install
pnpm run dev
```

## 주요 명령

- `pnpm run dev`: 로컬 개발 화면 실행
- `pnpm run build`: 배포용 빌드 검사
