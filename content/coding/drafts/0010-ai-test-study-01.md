## 1. 코드와 주석

핵심 코드만 가져오고, `왜 이렇게 작성했는지`를 주석으로 설명합니다.

```tsx
// 이 코드는 어디에서 실행되는지 설명합니다.
export default function Example() {
  // 이 값이 왜 필요한지 설명합니다.
  const message = "Hello, Popcorn!";

  // 화면에 무엇을 보여주는지 설명합니다.
  return <p>{message}</p>;
}
```

### 코드를 쉽게 설명하면

초등학생에게 설명하듯 코드의 동작 순서를 적습니다.

1. 먼저 무엇을 합니다.
2. 그다음 어떤 값을 확인합니다.
3. 마지막으로 화면에 무엇을 보여줍니다.
