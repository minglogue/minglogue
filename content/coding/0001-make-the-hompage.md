# 무엇을 만들었나요?

- 만들고 싶었던 것: 나만의 기록을 남겨둘 수 있는 홈페이지. 그런데 이제 블로그를 곁들인..

- 기존에 불편했던 점: 노션에 기록하자니 뭔가 자유도가 낮았다. 그리고 포트폴리오 겸 기록창고 겸 해서 만들게 됨

- 완성된 결과: 밍띠 전용 블로그 홈페이지 완성! 인데 오늘 할 부분은 html 역할을 하는 tsx파일의 일부이다.

## 1. 코드와 주석

```tsx
<section className="hero page-shell" id="top"> //section은 서로 관계있는 내용을 하나로 묶는 상자. 히어로페이지가 가장 눈에 띄는 부분(메인페이지)이라는 의미이고, 그 중 top(윗부분)이라는 고유 이름을 붙였음. 그리고 hero page-shell은 히어로부분 양옆에 여백을 주는 이름.
  <div className="hero-copy"> //div는 구분선이라는 의미고 여기서의 copy는 카피라이트의 카피임.
    <p className="eyebrow"> //eyebrow는 제목의 윗부분 작은 설명부를 뜻하는데 말그대로 눈썹부분에 있는 문장이라고해서 이렇게 이름붙임.
      DESIGNER BY DAY · DEVELOPER IN PROGRESS
    </p>

    <h1 className="pixel-copy">
      구조가 궁금해서,
      <br />
      직접 <span>분해해 봅니다.</span>
    </h1> //h1은 제목, br은 줄바꿈. span은 그부분을 작은 상자로 묶은 일종의 group인데 이부분만 다른 색이나 모양으로 꾸밀 수 있다. 내 경우는 밑줄표시!

    <p className="hero-intro">
      직접 해보고 실패한 모든 것을 기록합니다.
    </p>

    <Link className="text-link" href="/coding">
      최근 기록 읽기 <span>→</span>
    </Link> //링크인 이 부분을 누르면 coding페이지로 이동함. next.js가 제공하는 페이지 이동용 부품같은거.
  </div>

  <aside className="issue-card"> //본문 옆에 붙는 보조 내용을 뜻하는데 여기서는 [이번주 추천 글]카드 부분임.
    <p>THIS WEEK&apos;S LOG</p>
    <strong className="pixel-copy">#24</strong>

    <Link href={`/posts/${posts[0]?.slug ?? ""}`}>
      {posts[0]?.title ?? "첫 기록을 준비하고 있습니다."}
    </Link> //포스트의 첫번째(0)에 타이틀이 없다면(??) 우측의 문장을 노출해라 라는 뜻임. 글이 없으면 "첫 기록을 준비하고 있습니다."를 나타내라는 뜻.
  </aside>
</section> //지금까지 메인 히어로페이지의 상단부 섹션이었음.
```

### 코드를 쉽게 설명하면

1. section 이라는 큰 박스를 하나 만든다.
2. 그 다음 블럭들을 넣는다. 블럭은 하나하나 기능이 있거나 색, 모양이 있다.
3. 블럭에 들어갈 텍스트를 넣는다.
4. 사실 설명할 부분은 주석에서 다 한거같다.

## 3. 이번에 배운 것

- 새롭게 이해한 것: html에 대해서 좀 더 구체적으로 알게되었고, 코드들이 한 언어로만 작동하는게 아니라 뭔가 복합적으로 이 언어를 알면 저언어가 무슨기능하는지 감이 빨리 잡히는? 그런 개념들인 것 같다. 언어 하나만 파봐야겠다.

- 헷갈렸던 것: 왜 html에 Next.js가 한공간에서 작동하는거지...?

- 문제를 해결한 방법: 지피티에게 물어봤더니 우리가 작성한 TSX파일을 리액트와 넥스트js가 브라우저가 이해하는 hrml 로 번역해서 화면에 표시된다고 한다. 오... 그러니까 index.html은 화면 구조고 style.css는 꾸미는거, 이거까진 알고있었어. script.js가 행동이라고 비유함. 
	- 기존의 웹페이지는 버튼하나를 옮기고싶으면 이 세개를 다 수정했어야 하는데 리액트와 넥스트는 파일을 언어별로 나누는게 아니라 부품으로 나눴다.
	- 그래서 버튼에 필요한 구조(html)와 행동(js)를 하나의 부품(tsx)에 옮길 수 있었다.
	- tsx파일 안의 `<h1></h1>`은 JSX라는 문법이었삼!!!

- 다음에 다시 사용하고 싶은 방법: 다른 링크로 이동할 수 있는 `<Link></Link>`버튼 다시 써보고싶다. 자잘한 디자인도 좀 손보고싶고.
