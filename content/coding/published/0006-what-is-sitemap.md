# 사이트맵이란 무엇일까?

## 사이트맵의 정의

사이트맵(Sitemap)은 검색엔진에 홈페이지의 페이지 주소를 알려주는 파일이다.
쉽게 비유하면 사이트맵은 **홈페이지의 지도 또는 목차**다.
우리 홈페이지에는 다음과 같은 여러 페이지가 있다.
- 메인 페이지
- 코딩 글 목록
- 데일리 글 목록
- 푸딩이 갤러리
- 각각의 게시글

사람은 홈페이지의 메뉴를 누르면서 페이지를 찾을 수 있지만, Google 검색 로봇은 홈페이지 안의 링크를 하나씩 따라다니며 페이지를 찾아야 한다.

사이트맵은 Google에 다음과 같이 알려준다.

> “우리 홈페이지에는 이런 페이지들이 있습니다. 여기 적힌 주소들을 확인해 주세요.”

## 사이트맵 파일의 모습

사이트맵은 보통 `sitemap.xml`이라는 이름을 사용한다.

내 홈페이지의 사이트맵 주소는 다음과 같다.

```
https://blog.minglogue.workers.dev/sitemap.xml
```

사이트맵 안에는 페이지 주소와 수정 날짜 등이 기록된다.

```
<url>
  <loc>https://example.com/posts/0001</loc>
  <lastmod>2026-07-31</lastmod>
</url>
```

각 태그의 의미는 다음과 같다.

- `url`: 페이지 한 개의 정보를 묶는 상자
- `loc`: 페이지의 실제 주소
- `lastmod`: 페이지를 마지막으로 수정한 날짜

## 사이트맵이 필요한 이유

### 1. 검색엔진이 페이지를 발견하도록 돕는다

새 홈페이지는 다른 사이트에서 연결된 링크가 많지 않다.
Google은 다른 홈페이지의 링크를 따라가면서 새로운 페이지를 발견하기도 하는데, 새 사이트는 외부 링크가 적어서 발견되기까지 오래 걸릴 수 있다.
사이트맵을 제출하면 Google에 홈페이지와 게시글의 주소를 직접 알려줄 수 있다.

### 2. 새 게시글의 존재를 알려준다

사이트맵이 없다면 Google은 직접 홈페이지를 다시 방문해야 새 글이 생겼다는 사실을 알 수 있다.
사이트맵에는 공개된 게시글 주소가 포함되기 때문에 Google이 새로운 페이지를 발견하는 데 도움이 된다.
내 홈페이지에서는 `published: true`로 설정된 글만 사이트맵에 들어간다.

```
published: true
```

비공개 글은 사이트맵에서 제외된다.

### 3. 홈페이지의 전체 구조를 이해하도록 돕는다

사이트맵에는 메인 페이지뿐만 아니라 코딩, 데일리, 푸딩이 페이지와 각각의 게시글 주소가 들어 있다.
이를 통해 검색엔진은 홈페이지가 여러 페이지로 구성되어 있다는 사실을 더 쉽게 파악할 수 있다.

### 4. 수정된 페이지를 다시 확인하도록 돕는다

사이트맵에는 페이지의 마지막 수정 날짜를 기록할 수 있다.
검색엔진은 이 정보를 참고해 변경된 페이지를 다시 방문할지 판단할 수 있다.

## 사이트맵이 작동하는 과정

```
Markdown으로 새 글 작성
        ↓
published: true 설정
        ↓
Git commit
        ↓
GitHub에 push
        ↓
Cloudflare가 홈페이지 배포
        ↓
sitemap.xml에 새 글 주소 추가
        ↓
Google이 사이트맵 확인
        ↓
Google 검색 색인 후보가 됨
```

내 홈페이지는 Next.js를 사용하기 때문에 공개 글을 읽어 사이트맵을 자동으로 생성한다.
따라서 새 글을 작성할 때마다 `sitemap.xml`을 직접 수정할 필요는 없다.

## Search Console은 어떤 역할을 할까?

사이트맵 파일을 만들었다고 해서 Google이 그 주소를 즉시 확인하는 것은 아니다.
Google Search Console에서 사이트맵을 제출하면 Google에 다음과 같이 요청하는 것과 비슷하다.

> “사이트맵을 여기 만들어 두었으니 확인해 주세요.”

Search Console에는 다음 내용만 입력하면 된다.

```
sitemap.xml
```

Google은 이를 홈페이지 주소와 합쳐 전체 사이트맵 주소를 확인한다.

```
홈페이지 주소
https://blog.minglogue.workers.dev/

입력한 주소
sitemap.xml

최종 주소
https://blog.minglogue.workers.dev/sitemap.xml
```

## 사이트맵이 있으면 무조건 검색될까?

사이트맵은 검색 노출을 보장하지 않는다.

사이트맵의 역할은 Google에 페이지의 존재를 알려주는 것이다. 실제 검색 등록과 검색 순위는 Google이 콘텐츠를 확인한 뒤 결정한다.

```
사이트맵 제출
≠ 검색 결과 즉시 노출
≠ 검색 순위 상승 보장
```

검색에 잘 노출되려면 사이트맵뿐만 아니라 다음 요소도 필요하다.

- 검색 질문에 도움이 되는 내용
- 내용을 정확하게 설명하는 제목
- 글마다 다른 요약문
- `h1`, `h2`, `h3`를 사용한 읽기 쉬운 구조
- 관련 게시글을 연결하는 내부 링크
- 이미지의 대체 설명
- 작성자와 작성 날짜
- 꾸준한 글 작성과 업데이트

## robots.txt와 사이트맵의 차이

`robots.txt`와 `sitemap.xml`은 역할이 다르다.

```
robots.txt
→ 검색 로봇이 어디에 들어가도 되는지 알려주는 안내문

sitemap.xml
→ 검색 로봇이 확인할 페이지 주소를 모아놓은 지도
```

내 홈페이지의 `robots.txt`에서는 일반 페이지의 접근을 허용하고, 글쓰기 관리 화면인 `/studio`는 검색하지 않도록 설정했다.

```
User-Agent: *
Allow: /
Disallow: /studio
```

그리고 검색 로봇이 사이트맵을 찾을 수 있도록 사이트맵 주소도 안내한다.

## 한 줄 정리

> 사이트맵은 검색엔진에 홈페이지의 공개 페이지 주소와 구조를 알려주는 지도이며, Google이 새 글을 발견하고 수집하는 데 도움을 주는 파일이다.
