# 무엇을 만들었나요?

오랜만에 홈페이지 업데이트를 했다. 이직 준비로 바쁘게 주말을 보내 오랜만에 올리는듯?
그리고 지난주 금요일에 GPT 크레딧을 다써서 새로 채워지는동안 이력서 접수에 힘을 썼다.
포트폴리오를 여기 올린 뒤 링크를 보냈더니 좀 더 반응이 좋았던 것 같다.
링크보냈던 프로젝트 하나를 PPT형태로 가져와달래서 인쇄용으로 하나 만들었는데, 생각해보니 내 프로젝트 글 안에 PDF로 다운받기 버튼이 있으면 좋겠다는 생각이 들었다.

## 2. 이번에 배운 것

그래서 버튼을 만들어서 포트폴리오를 본 분들이 바로 pdf로 다운받아 채용과정을 원활하게 진행할 수 있도록 했다. 다른 프로젝트도 하나씩 pdf파일로 만들어야겠다.

- 좋았던 것: 하나씩 기능들이 추가될 때마다 애착이 생긴다.
- 어려웠던 것: pdf 첨부 기능은 속성에 파일을 추가해서 저장하면 나오고 그게 아니면 버튼 노출이 안되도록 했는데, 버튼노출이 안돼서 한 번 더 점검했다.
- 다음에는 이렇게 해보고 싶은 것: 추가적으로 다운받기 말고도 pdf로 미리보기같은것도 구현하면 좋을 것 같다. PPT 형식은 글과는 완전히 다른형태라, 미리보기로 본 뒤 다운받게 하는것도 괜찮을듯
