# 무엇을 만들었나요?

- 만들고 싶었던 것: 푸딩이 갤러리뷰
- 기존에 불편했던 점: 푸딩이 공간을 인스타에 연결하려했는데 아직 급한게 아니라 보류함
- 완성된 결과: 푸딩이 사진과 태그를 간단하게 올릴 수 있음.

## 1. 막혔던 부분

- 푸딩이 사진이 한개만 나오고 있었다. 본문은 잘 노출되는데..?
- 알고보니 글 템플릿에 imege라는 속성이 있었다. 그래서 photo.jpg 이미지 하나만 가져오고 있었음.

## 2. 코드와 주석


```yaml
image: ./photo.jpg
```

### 코드를 쉽게 설명하면

pudding or media 폴더의 photo.jpg파일을 이미지로 가져오라는 뜻

## 2. 해당 부분 이미지


> ![[pudding-gallery-duplicate-image.png]]
푸딩이 이미지가 하나만 나온다.

## 3. 이번에 배운 것

- 새롭게 이해한 것: 지피티가 주는대로 무조건 따르지 말자. 진짜 내가 이해하고 넘어가자.
- 헷갈렸던 것: 푸딩이 사진이 왜 같은 사진 하나만 뜨는지?
- 문제를 해결한 방법: image속성을 아예 삭제함.
- 다음에 다시 사용하고 싶은 방법: 이미지는 직접 불러온 이미지가 노출되게 한다.


## 한 줄 정리

푸딩이 사진은 속성이 아니라 본문에 있는걸로 노출되도록 하자.
