# 무엇을 만들었나요?

- 만들고 싶었던 것: 메인페이지의 글목록은 5개까지만 불러오고싶어
- 기존에 불편했던 점: 글목록이 너무 크고 3개까지밖에 안보였다.
- 완성된 결과: 글목록을 카테고리 | 제목 | 소제목 | 날짜 로 한줄로 나오도록 줄이고 메인에서 최대 5개까지 보이도록 함 

## 1. 코드와 주석

```tsx
const posts = codingPosts.slice(0, 5);
```

```tsx
const latestPudding = getPuddingPosts()[0];
```
### 코드를 쉽게 설명하면

1. 첫번째 코드 : 코딩 글 전체 중 최신 5개 글까지 잘라낸다. (0부터 시작해서 5개)
2. 두번째 코드 : 푸딩이 글은 최신 글 하나만 가져온다.
3. 마지막으로 화면에 무엇을 보여줍니다.
