# 화면 뒤를 상상하게 됐다

예전에는 완성된 화면을 먼저 봤다. 개발을 배우고 나서는 버튼 하나를 보면서도 상태, 데이터, 예외 상황을 함께 생각하게 된다.

디자인과 개발 중 하나를 선택하기보다, 두 관점 사이를 오갈 수 있는 사람이 되고 싶다.
